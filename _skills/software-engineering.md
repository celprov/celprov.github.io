### Summary
Software engineering principles were applied throughout my thesis to create robust, maintainable, and reproducible research tools. I developed comprehensive Standard Operating Procedures (SOPs) in Markdown format, ensuring clear documentation and version control. Testing frameworks with Pytest improved code reliability, while contributions to open-source neuroimaging tools like MRIQC and fMRIPrep enhanced community-wide data processing capabilities.

### Representative work
- **Markdown SOPs**: Created comprehensive documentation of neuroimaging workflows using Git-based version control, enabling reproducible and traceable research procedures [SOPs repository, axonlab.org/hcph-sops].
- **Pytest FC suite**: Implemented testing frameworks for neuroimaging data processing pipelines, ensuring code integrity and preventing regression bugs in automated analysis workflows [GitHub contributions].
- **CI/CD integration**: Developed continuous integration and deployment workflows for neuroimaging software, automating testing and deployment of research tools [Project contributions].
- **OSS contributions**: Enhanced MRIQC and fMRIPrep software with new visual quality assessment tools and improved workflow robustness, benefiting the broader neuroimaging community [GitHub PRs].
