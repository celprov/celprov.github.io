### Summary
Data engineering skills were crucial for managing the complexity and volume of neuroimaging datasets throughout my thesis. I developed automated pipelines for high-performance computing environments to process large-scale fMRI and dMRI data. Containerization with Docker improved reproducibility across different computing environments, while Datalad was used for version control of medical imaging datasets, ensuring data provenance and integrity during analysis workflows.

### Representative work
- **PhysioQC development**: Built physiological signal quality control tools for neuroimaging studies, implementing automated detection algorithms for cardiac and respiratory artifacts [GitHub contributions].
- **HCPh preprocessing**: Designed containerized preprocessing pipelines on HPC for Human Connectome Phantom multi-modal neuroimaging data, enabling scalable analysis of repeated scans [Thesis].
- **q'kay web app**: Developed a web-based management system for large-scale manual quality rating collections using Docker containerization, improving workflow efficiency for QA/QC processes [Conference poster, OHBM 2023].
- **Datalad version control**: Implemented data versioning systems for neuroimaging datasets, ensuring reproducible and traceable analysis workflows across research projects [SOPs repository].
